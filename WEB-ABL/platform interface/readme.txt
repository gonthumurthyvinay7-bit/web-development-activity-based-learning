### 1. LearnHub (Online Learning Website)

**Files:** `platform_interface.html` and its `style.css`

A simple website for learning new skills online.

What is on the page:
- A header with menu links (Home, Courses, About)
- A welcome section with an "Explore Courses" button
- Course categories (Programming, Web Development, Python, AI)
- Three course cards: HTML & CSS, Python Programming, and Artificial Intelligence
- Each card shows the instructor name, learning goals, a progress bar, and an "Enroll Now" button
- An About section and a footer
